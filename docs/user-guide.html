01 · Quick start

Get a paper run in minutes

You need a recent Rust toolchain. PostgreSQL is optional for local demos. 

git clone https://github.com/SteveDexter24/trading.git
cd trading
cargo test --workspace --all-features
cargo run --bin trading-engine

Without DATABASE_URL, the engine uses an in-memory adapter. With Docker: docker compose up --build starts Postgres and the engine.

02 · Architecture

Trading and ML stay in separate crates

They share domain contracts for features, predictions, and signals. ML never sizes or approves orders.

Path Job
crates/strategy → risk → execution → paper-broker Live paper trading path
crates/ml-inference Versioned scoring boundary (no training)
crates/research + apps/backtester Walk-forward backtests and metrics
research/python Offline train + ONNX export
crates/domain Shared types and ports
1. Features (quote-momentum-v1) 2. Predictor scores → ScoredPrediction 3. Strategy may emit Signal 4. Risk sizes / approves (or blocks) 5. Paper broker fills
03 · Paper engine

Run the synthetic end-to-end flow

trading-engine processes one synthetic quote through strategy, risk, paper broker, and fill, then logs a JSON audit result. 

# in-memory
cargo run --bin trading-engine

# with Postgres (migrations apply on connect)
export DATABASE_URL='postgres://trading:local-development-only@localhost:5432/trading'
cargo run --bin trading-engine

# or via Compose
docker compose up --build

Mode is fixed to Paper. Production Webull submission has no constructible path in this codebase.

04 · Status API

Inspect state; flip the kill switch

The API is read-only for trading data. There is no order-entry route. Listen address: 0.0.0.0:8080. 

export ADMIN_API_TOKEN='replace-me'
# optional shared DB with the engine:
# export DATABASE_URL='postgres://trading:local-development-only@localhost:5432/trading'
cargo run --bin trading-api
Method Path Notes
GET /health Liveness
GET /ready Storage reachable
GET /v1/status Paper mode + kill-switch flag
GET /v1/orders, /fills, /risk-decisions Persisted collections
GET /v1/portfolio, /positions, /signals Stub empty collections in this revision
POST /v1/system/kill-switch Bearer ADMIN_API_TOKEN required 
curl -s http://127.0.0.1:8080/v1/status | jq

curl -s -X POST http://127.0.0.1:8080/v1/system/kill-switch \
  -H "Authorization: Bearer replace-me" \
  -H "Content-Type: application/json" \
  -d '{"active": true}'
05 · Research backtester

Walk-forward with prediction-gated signals

Reuses strategy and risk ports under a simulation clock. Today it scores with DeterministicResearchModel until ONNX runtime wiring lands. 

cargo run --bin trading-backtester

Logs walk-forward train / validation / test windows, then a metrics report (CAGR proxy, volatility, Sharpe, Sortino, drawdown, turnover, hit rate, exposure, costs, benchmark).

06 · Offline ML

Train outside the Rust runtime

Python lives in research/python. Export frozen ONNX + metadata; Rust only scores. Predictions may propose signals — risk still decides. 

cd research/python
python -m venv .venv
source .venv/bin/activate
pip install -e .
python -m trading_research_offline.train_baseline --output-dir artifacts

Writes artifacts/offline-logistic-quote-momentum-v1.onnx and a matching .json digest/metadata file. Point OnnxPredictor at the artifact after the ONNX runtime path is enabled.

07 · Config & safety

Environment and hard limits

Inject secrets through the process environment or a secret manager. Do not commit env files. Never log Webull credentials or account IDs.

Variable Used by Purpose
DATABASE_URL Engine, API Postgres; omit for in-memory
ADMIN_API_TOKEN API Bearer token for kill switch
RUST_LOG All apps Tracing filter (default info)

Fail-closed: paper mode only; Webull production submission is disabled in code; the sandbox adapter also refuses submit in this iteration; intents persist before broker actions.

08 · Verify

Same checks as CI

Run these before merging changes. Postgres integration tests activate when TEST_DATABASE_URL is set. 

cargo fmt --all --check
cargo clippy --workspace --all-targets --all-features -- -D warnings
cargo test --workspace --all-features
cargo run --bin trading-engine
cargo run --bin trading-backtester
